# Peshaant Gunness · Portfolio

Personal portfolio site: who I am, what I work with, and what I've built. I'm a third-year Computer Science student at Monash University Malaysia, focused on cybersecurity, data science, and AI.

## Sections
- **Hero & status**: current focus, internship availability (Nov 2026 – Feb 2027), location and certifications
- **About**: background and highlights
- **Skills**: security, AI/data science, languages, software engineering and systems
- **Projects**: hackathon and personal projects, with links to their repos
- **Contact**: email, GitHub and LinkedIn

## Tech stack
- [Next.js](https://nextjs.org) 16 (App Router) with React 19 and TypeScript
- [Tailwind CSS](https://tailwindcss.com) 4
- [Framer Motion](https://www.framer.com/motion/) for scroll-in animations
- [Lucide](https://lucide.dev) icons

## Project structure
```
src/
├── app/            layout, global styles and the single page
├── components/     Navbar, Hero, About, Skills, Projects, Contact
└── data/
    └── projects.ts project list: edit this to add or update projects
```

## Running locally
Requires Node 18+.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
